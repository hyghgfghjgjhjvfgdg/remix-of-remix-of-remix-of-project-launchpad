- `electron/` is a standalone desktop UI (`renderer/` HTML/CSS/JS, frameless window, own skeleton) fed by the active site's `/api/public/app-latest` via IPC in `main.cjs`, cached in userData for offline start; it never loads the website as its main window (Watch opens a separate player window). Why: user wants its own app, not the website.
- Windows release = one NSIS setup (`build/installer.nsi`, built with `nix shell nixpkgs#nsis -c makensis` after @electron/packager) with desktop-shortcut + launch checkboxes; uploaded as a Lovable asset pointer used by the desktop Install button. Why: user wants a single setup .exe, not a zip.
